## 📌 주요 기술 스택

### Backend
- **Django 5.2** + **Django REST Framework 3.16**
- **PostgreSQL** (배포) / **SQLite** (로컬)
- **OpenAI API** (text-embedding-3-small)
- **KOPIS API** (공연 데이터)
- **JWT Authentication** (simplejwt)

### Frontend
- **Vue 3** (Composition API)
- **Pinia** (상태 관리)
- **Vue Router 4**
- **Axios** (API 통신)
- **Tailwind CSS** (스타일링)

### AI/ML
- **OpenAI Embeddings** (의미 기반 검색)
- **Cosine Similarity** (벡터 유사도)
- **하이브리드 추천 엔진** (콘텐츠 기반 + 협업 필터링)

### Deployment
- **AWS EC2** (백엔드/프론트엔드 분리)
- **Nginx** (프론트엔드 서빙)
- **Django Development Server** (백엔드)

## 🏆 핵심 구현 기능

### 1. AI 기반 추천 시스템
- **7개 점수 함수** 조합 하이브리드 알고리즘
- 장르 적합도, 인기도, 신선도, 지역 가중치 등
- 사용자 행동 패턴 기반 개인화

### 2. 의미 기반 검색
- OpenAI Embedding을 활용한 자연어 질의
- "가족과 함께 볼 만한 뮤지컬" 같은 자연스러운 검색
- 코사인 유사도 기반 정확한 매칭

### 3. Tinder 스타일 온보딩
- 스와이프 UI로 선호 장르 수집
- 초기 추천 데이터 생성
- 직관적인 사용자 경험

### 4. 관람함 시스템
- 보고싶어요 / 본 공연 / 관람중 상태 관리
- 평점 및 감상 기록
- 개인화된 공연 히스토리

### 5. JWT 인증
- Access/Refresh Token 자동 갱신
- Axios 인터셉터 통한 투명한 인증
- 보안성 높은 토큰 관리
