## 개요

### 목적
사용자의 행동 패턴, 선호도, 위치 정보를 종합하여 **개인화된 공연 추천**을 제공하는 하이브리드 추천 시스템

### 핵심 특징
- **6가지 점수 함수** 기반 하이브리드 알고리즘
- **Time Decay** 적용으로 최신 행동에 더 높은 가중치
- **캐싱 전략**으로 실시간 응답 성능 향상
- **개인화된 추천 사유** 제공 (왜 추천되었는지 설명)

### 기술 스택
- **Backend**: Django REST Framework, Python
- **Frontend**: Vue.js 3 (Composition API), Pinia
- **Database**: MySQL (User Logs, Cache)
- **Algorithm**: Weighted Hybrid Recommendation

## 하이브리드 추천 알고리즘

### 수식 정의

개별 공연 `p`에 대한 사용자 `u`의 **총점수 S(u, p)**는 다음과 같이 계산됩니다:

```
S(u, p) = w1·f1(u, p) + w2·f2(u, p) + w3·f3(u, p) + w4·f4(p) + w5·f5(p) + w6·f6(u, p)
```

#### 가중치 (Weights)

| 함수 | 설명 | 가중치 |
|------|------|--------|
| **f1** | 클릭/관심 로그 기반 (Time Decay) | 25% (0.25) |
| **f2** | 취향 매칭 (선호 장르/배우) | 20% (0.20) |
| **f3** | 위치 근접성 (지역 매칭) | 15% (0.15) |
| **f4** | 대중성 (인기도) | 15% (0.15) |
| **f5** | 최신성 (공연 시작일 임박도) | 10% (0.10) |
| **f6** | 협업 필터링 (유사 사용자 선호) | 15% (0.15) |

---

### 각 점수 함수 상세

#### f1: 클릭/관심 로그 기반 점수

**목적**: 사용자가 최근에 본 공연과 유사한 장르의 공연에 높은 점수 부여

**수식**:
```
f1(u, p) = min(Σ [action_score × λ^t] / 10, 1.0)

여기서:
- action_score: view=1, like=3, search=2
- λ (lambda): 0.95 (Time Decay 계수)
- t: 행동 발생 후 경과 일수
```

**구현** ([engine.py:138-169](../back/recommendations/engine.py#L138-L169)):
```python
def _f1_click_score(self, performance):
    from recommendations.models import UserLog

    # 최근 30일간의 로그만 고려
    recent_date = timezone.now() - timedelta(days=30)
    logs = UserLog.objects.filter(
        user=self.user,
        timestamp__gte=recent_date
    ).select_related('performance')

    if not logs.exists():
        return 0.0

    score = 0.0
    for log in logs:
        # 장르 일치 여부
        if log.performance.genrenm == performance.genrenm:
            # 행동 유형에 따른 기본 점수
            base_score = self.ACTION_SCORES.get(log.action_type, 1)

            # Time Decay 적용
            days_ago = (timezone.now() - log.timestamp).days
            decayed_score = base_score * (self.DECAY_LAMBDA ** days_ago)

            score += decayed_score

    # 0~1 사이로 정규화
    return min(score / 10.0, 1.0)
```

**예시**:
- 사용자가 3일 전 뮤지컬 A를 찜 (like): `3 × 0.95^3 = 2.57`
- 사용자가 10일 전 뮤지컬 B를 조회 (view): `1 × 0.95^10 = 0.60`
- 뮤지컬 C에 대한 f1 점수: `(2.57 + 0.60) / 10 = 0.317`

#### f2: 취향 매칭 점수

**목적**: 사용자 프로필의 선호 태그와 배우 정보를 공연과 매칭

**수식**:
```
f2(u, p) = genre_match × 0.6 + actor_match × 0.4

여기서:
- genre_match: 사용자 preference_tags와 공연 장르 일치 여부 (0 or 1)
- actor_match: 사용자 favorite_actors와 공연 출연진 일치 여부 (0 or 1)
```

**구현** ([engine.py:171-194](../back/recommendations/engine.py#L171-L194)):
```python
def _f2_preference_score(self, performance):
    score = 0.0

    # 1. 장르 태그 매칭 (60%)
    if self.user.preference_tags and performance.genrenm:
        for tag in self.user.preference_tags:
            if tag in performance.genrenm:
                score += 0.6
                break

    # 2. 배우 매칭 (40%)
    if self.user.favorite_actors and performance.cast_search_text:
        for actor in self.user.favorite_actors:
            if actor in performance.cast_search_text:
                score += 0.4
                break

    return min(score, 1.0)
```

**예시**:
- User A의 preference_tags: `["뮤지컬", "로맨틱"]`
- User A의 favorite_actors: `["조승우"]`
- 뮤지컬 "레베카" (장르: 뮤지컬, 출연: 조승우): `f2 = 0.6 + 0.4 = 1.0`

#### f3: 위치 근접성 점수

**목적**: 사용자의 거주 지역과 가까운 공연장에 높은 점수 부여

**방식**: 텍스트 매칭 (Phase 1)
- 구(Gu) 완전 일치: 1.0
- 시/도 레벨 일치: 0.6
- 불일치: 0.0
- 정보 없음: 0.5 (중립)

**구현** ([engine.py:196-220](../back/recommendations/engine.py#L196-L220)):
```python
def _f3_location_score(self, performance):
    if not self.user.region_gu or not performance.area:
        return 0.5  # 정보 없으면 중립 점수

    # 1. 구(Gu) 완전 일치 -> 최고 점수
    if self.user.region_gu in performance.area:
        return 1.0

    # 2. 시/도 레벨 일치
    user_city = self._extract_city(self.user.region_gu)
    if user_city and user_city in performance.area:
        return 0.6

    return 0.0
```

**예시**:
- User B의 region_gu: `"강남구"`
- 공연 X (area: "서울 강남구"): `f3 = 1.0`
- 공연 Y (area: "서울 종로구"): `f3 = 0.6`
- 공연 Z (area: "부산 해운대구"): `f3 = 0.0`

**향후 개선 (Phase 2)**:
- Kakao Geocoding API로 좌표 변환
- 실제 거리 기반 점수 계산: `score = 1 / (1 + distance_km / 5)`

#### f4: 대중성 점수

**목적**: 많은 사람들이 선호하는 인기 공연에 높은 점수

**데이터 소스**:
1. **PerformanceMetric.score_popularity** (우선)
2. BoxOffice 랭킹 (대체)

**구현** ([engine.py:216-235](../back/recommendations/engine.py#L216-L235)):
```python
def _f4_popularity_score(self, performance):
    # PerformanceMetric 활용
    try:
        if hasattr(performance, 'metric') and performance.metric:
            return performance.metric.score_popularity
    except:
        pass

    # BoxOffice 랭킹으로 대체
    if hasattr(performance, 'box_office_rankings'):
        rankings = performance.box_office_rankings.all()
        if rankings.exists():
            best_rank = min([r.rank for r in rankings])
            return max(0, 1 - (best_rank - 1) / 10)

    return 0.3  # 기본 점수
```

**예시**:
- 박스오피스 1위: `f4 = 1.0`
- 박스오피스 5위: `f4 = 0.6`
- 랭킹 없음: `f4 = 0.3`

#### f5: 최신성 점수

**목적**: 곧 시작하는 공연을 우선 추천 (마감 임박 효과)

**수식** (시그모이드 함수):
```
f5(p) = 1 / (1 + e^(0.1 × (days_until_start - 15)))

여기서 days_until_start: 공연 시작일까지 남은 일수
```

**구현** ([engine.py:237-262](../back/recommendations/engine.py#L237-L262)):
```python
def _f5_recency_score(self, performance):
    try:
        if hasattr(performance, 'metric') and performance.metric:
            return performance.metric.score_recency
    except:
        pass

    if not performance.prfpdfrom:
        return 0.5

    today = timezone.now().date()
    days_until_start = (performance.prfpdfrom - today).days

    if days_until_start < 0:
        # 이미 시작한 공연
        return 0.7
    else:
        # 시작 예정 공연 (시그모이드)
        return 1 / (1 + math.exp(0.1 * (days_until_start - 15)))
```

**예시**:
- 내일 시작 (D-1): `f5 ≈ 0.95`
- 15일 후 시작 (D-15): `f5 = 0.5`
- 30일 후 시작 (D-30): `f5 ≈ 0.18`

#### f6: 협업 필터링 점수

**목적**: 사용자가 좋아한 공연과 유사한 공연 추천

**데이터 소스**:
1. **PerformanceMetric.similar_performances** (우선)
2. 장르 유사도 (대체)

**구현** ([engine.py:264-301](../back/recommendations/engine.py#L264-L301)):
```python
def _f6_collaborative_score(self, performance):
    from recommendations.models import UserLog

    # 사용자가 'like'한 공연들 조회
    liked_performances = UserLog.objects.filter(
        user=self.user,
        action_type='like'
    ).values_list('performance_id', flat=True)[:10]

    if not liked_performances:
        return 0.5

    # PerformanceMetric의 similar_performances 활용
    try:
        if hasattr(performance, 'metric') and performance.metric:
            similar_list = performance.metric.similar_performances
            if similar_list:
                overlap_count = sum(1 for pid in liked_performances if pid in similar_list)
                return min(overlap_count / 3.0, 1.0)
    except:
        pass

    # 장르 유사도로 대체
    for liked_id in liked_performances:
        try:
            liked_perf = Performance.objects.get(mt20id=liked_id)
            if liked_perf.genrenm == performance.genrenm:
                return 0.7
        except:
            continue

    return 0.3
```

**예시**:
- User C가 찜한 공연: ["뮤지컬 A", "뮤지컬 B"]
- 공연 X의 유사 공연: ["뮤지컬 A", "뮤지컬 C"]
- 겹치는 개수: 1개 → `f6 = 1/3 = 0.33`

### 2. RecommendationCache (추천 결과 캐시)

**목적**: 계산 비용이 높은 추천 결과를 캐싱하여 응답 속도 향상

```python
class RecommendationCache(models.Model):
    user = models.OneToOneField(User, primary_key=True, on_delete=models.CASCADE)
    top_n_list = models.JSONField(default=list, blank=True)
    # [{"mt20id": "PF123", "score": 0.85, "reason": "location"}, ...]
    updated_at = models.DateTimeField(auto_now=True)

    def is_fresh(self, max_age_hours=1):
        """캐시 유효성 확인 (기본 TTL: 1시간)"""
        age = timezone.now() - self.updated_at
        return age < timedelta(hours=max_age_hours)
```

**캐싱 전략**:
1. **TTL**: 1시간 (커스터마이징 가능)

   - `/refresh/` API 호출 시 (강제)

```python
@action(detail=True, methods=['post'], permission_classes=[IsAuthenticated])
def like(self, request, pk=None):
    performance = self.get_object()
    user = request.user

    if user in performance.like_users.all():
        performance.like_users.remove(user)
        is_liked = False
    else:
        performance.like_users.add(user)
        is_liked = True

        # UserLog 자동 생성

            user=user,
            performance=performance,
            action_type='like'
        )

    return Response({
        'success': True,
        'is_liked': is_liked,
        'like_count': performance.like_users.count()
```

### 2. 딥러닝 기반 추천

**Neural Collaborative Filtering (NCF)**:
- User Embedding + Item Embedding
- MLP로 비선형 관계 학습

**구현 프레임워크**: PyTorch, TensorFlow

**예시**:
```python
import torch
import torch.nn as nn

class NCFModel(nn.Module):
    def __init__(self, num_users, num_items, embedding_dim=64):
        super().__init__()
        self.user_embedding = nn.Embedding(num_users, embedding_dim)
        self.item_embedding = nn.Embedding(num_items, embedding_dim)
        self.fc = nn.Sequential(
            nn.Linear(embedding_dim * 2, 128),
            nn.ReLU(),
            nn.Linear(128, 64),
            nn.ReLU(),
            nn.Linear(64, 1),
            nn.Sigmoid()
        )

    def forward(self, user_ids, item_ids):
        user_emb = self.user_embedding(user_ids)
        item_emb = self.item_embedding(item_ids)
        x = torch.cat([user_emb, item_emb], dim=-1)
        return self.fc(x)
```

#### 2. 의미 기반 협업 필터링 (f6 강화)

**현재 구현**:
```python
# engine.py의 _f6_collaborative_score
def _f6_collaborative_score(self, performance):
    # PerformanceMetric.similar_performances 활용 (통계 기반)
    if similar_list:
        overlap_count = sum(1 for pid in liked_performances if pid in similar_list)
```

**AI 개선안**:
```python
def _f6_collaborative_score_with_ai(self, performance):
    """임베딩 기반 의미 유사도 추가"""
    # 1. 기존 통계 기반 점수
    base_score = self._f6_collaborative_score(performance)

    # 2. 임베딩 기반 점수 (공연 소개글 의미 비교)
    if performance.embedding_vector:
        # 사용자가 좋아한 공연들의 평균 임베딩
        liked_embeddings = [
            perf.embedding_vector
            for perf in self.user.favorite_performances.all()
            if perf.embedding_vector
        ]

        if liked_embeddings:
            avg_liked_embedding = np.mean(liked_embeddings, axis=0)

            # 코사인 유사도 계산
            similarity = cosine_similarity(
                [avg_liked_embedding],
                [performance.embedding_vector]
            )[0][0]

            embedding_score = max(0, similarity)  # 0~1 정규화

            # 통계 + 의미 유사도 조합 (7:3)
            return base_score * 0.7 + embedding_score * 0.3

    return base_score
```

**임베딩 DB 구조**:

```python
    # ... 기존 필드 ...

    # 임베딩 필드 추가
    embedding_vector = models.JSONField(
        null=True,
        blank=True,
        help_text="text-embedding-3-small (1536 차원)"
    )
    embedding_updated_at = models.DateTimeField(null=True, blank=True)

    def update_embedding(self):
        """공연 소개글을 임베딩으로 변환"""
        text = f"{self.prfnm} {self.genrenm} {self.prfcast}"

        response = openai.Embedding.create(
            model="text-embedding-3-small",
            input=text
        )

        self.embedding_vector = response.data[0].embedding
        self.embedding_updated_at = timezone.now()
        self.save()
```

**차별점**:
- 기존: "A를 좋아한 사람이 B도 좋아함" (통계)

#### 3. 리뷰 감정 분석 & 자동 요약

**기능**: 공연당 수십 개 리뷰를 AI가 3줄로 요약

**구현 위치**: ArticleDetailSerializer

**구현 예시**:
```python
# serializers.py
class ArticleDetailSerializer(serializers.ModelSerializer):
    # ... 기존 필드 ...
    review_summary = serializers.SerializerMethodField()

    def get_review_summary(self, obj):
        """리뷰 요약 (캐싱 활용)"""
        cache_key = f"review_summary_{obj.id}"
        cached = cache.get(cache_key)

        if cached:
            return cached

        # 최근 리뷰 30개 수집
        reviews = obj.comments.order_by('-created_at')[:30]
        review_texts = [r.content for r in reviews]

        if len(review_texts) < 5:
            return None

        prompt = f"""
        다음은 "{obj.title}" 공연에 대한 실제 관객 리뷰입니다:

        {chr(10).join(review_texts)}

        위 리뷰들을 분석하여 다음 형식으로 요약해주세요:

        ✅ 긍정 포인트 (2가지)
        ❌ 개선 포인트 (1가지)
        ⭐ 종합 평가 (1문장)
        """

        response = openai.ChatCompletion.create(
            model="gpt-4o-mini",
            messages=[{"role": "user", "content": prompt}],
            max_tokens=300
        )

        summary = response.choices[0].message.content

        # 1시간 캐싱
        cache.set(cache_key, summary, 3600)

        return summary
```

**출력 예시**:
```
✅ 긍정 포인트:
   • 배우들의 연기력과 무대 연출이 압도적 (92%)

❌ 개선 포인트:

   전반적으로 매우 만족스러운 공연으로 평가받고 있으며,
   특히 연기와 연출에서 높은 점수를 받았습니다.
```

#### 4. 의미 기반 공연 검색

**현재**: 제목/장르 키워드 매칭

**AI 개선안**: 자연어 검색 지원

| 검색어 | 기존 결과 | AI 검색 결과 |
|--------|----------|-------------|
| "감동적인 사랑 이야기" | ❌ 없음 | ✅ 로맨틱 뮤지컬, 사랑 테마 연극 |
| "가족이랑 볼만한" | ❌ "가족" 키워드만 | ✅ 전연령, 어린이 환영 공연 |
| "웃긴 공연" | ❌ "웃긴" 포함만 | ✅ 코미디, 개그, 유쾌한 공연 |

**구현**:
```python
# api_views.py
def semantic_search(query_text, top_k=10):
    """의미 기반 검색"""
    # 1. 검색어를 임베딩
    query_embedding = openai.Embedding.create(
        model="text-embedding-3-small",
        input=query_text
    ).data[0].embedding

    # 2. 모든 공연과 유사도 계산
    performances = Performance.objects.filter(
        embedding_vector__isnull=False
    )

    similarities = []
    for perf in performances:
        similarity = cosine_similarity(
            [query_embedding],
            [perf.embedding_vector]
        )[0][0]
        similarities.append((perf, similarity))

    # 3. 유사도 높은 순 정렬
    similarities.sort(key=lambda x: x[1], reverse=True)

    return [perf for perf, score in similarities[:top_k]]
```

**구현 난이도**: ⭐⭐
**예상 비용**: 월 $5
**효과**: 검색 성공률 60% → 85%
