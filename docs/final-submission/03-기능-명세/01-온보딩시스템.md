## 🎯 기능 설명

### 주요 기능
- 신규 사용자 대상 최초 1회 필수 온보딩 프로세스
- 16개의 공연 카드 제시 및 선호도 수집 (3단계: 보고싶음/모르겠음/안보고싶음)
- 최소 8개 이상 선택 시 완료 가능
- 사용자 반응을 기반으로 1536차원 선호도 벡터 생성
- 벡터 기반 코사인 유사도를 활용한 개인화 추천

### 핵심 알고리즘
```
1. 사용자가 16개 공연 중 N개(≥8) 선택
2. 각 선택에 가중치 부여:
   - 보고싶어요: +1.5
   - 모르겠어요: 0 (무시)
   - 안보고싶어요: -1.0

3. 선호도 벡터 계산:
   preference_vector = Σ(weight_i × embedding_i) / ||Σ(weight_i × embedding_i)||

4. 추천 시 코사인 유사도 계산:
   similarity = cos(user_vector, performance_vector)
```

#### 2. calculate_preference_vector()
```python
def calculate_preference_vector(user):
    """
    사용자 선호도 벡터 계산

    Algorithm:
    1. UserPerformanceSignal에서 사용자 신호 조회
    2. 각 신호의 가중치와 공연 임베딩 곱셈
    3. 가중합 계산: Σ(weight_i × embedding_i)
    4. L2 정규화

    Returns: 1536-dim normalized vector (list)
    """
    signals = UserPerformanceSignal.objects.filter(
        user=user,
        performance__embedding__isnull=False
    ).select_related('performance__embedding')

    if signals.count() == 0:
        return [0.0] * 1536

    # 가중합 계산
    weighted_sum = np.zeros(1536, dtype=np.float32)
    for signal_obj in signals:
        embedding_vector = np.array(signal_obj.performance.embedding.vector)
        weight = signal_obj.signal
        weighted_sum += weight * embedding_vector

    # L2 정규화
    norm = np.linalg.norm(weighted_sum)
    if norm > 0:
        normalized = weighted_sum / norm
    else:
        normalized = weighted_sum

    return normalized.tolist()
```

#### 3. complete_onboarding()
```python
def complete_onboarding(user):
    """
    온보딩 완료 처리

    Steps:
    1. 선호도 벡터 계산
    2. UserPreference 생성/업데이트
    3. User.has_onboarded = True
    4. User.onboarded_at = now()

    Returns: UserPreference instance
    """
    preference_vector = calculate_preference_vector(user)
    signal_count = UserPerformanceSignal.objects.filter(user=user).count()

    preference, created = UserPreference.objects.update_or_create(
        user=user,
        defaults={
            'preference_vector': preference_vector,
            'signal_count': signal_count
        }
    )

    user.has_onboarded = True
    user.onboarded_at = timezone.now()
    user.save(update_fields=['has_onboarded', 'onboarded_at'])

    return preference
```

#### 2. 임베딩 유사도 계산
```python
def _score_f7_embedding(self, performance, user_preference_vector):
    """
    Factor 7: 임베딩 유사도 점수

    코사인 유사도를 0-1 범위로 스케일링
    """
    if not user_preference_vector:
        return 0.0

    try:
        embedding = performance.embedding.vector

        import numpy as np
        user_vec = np.array(user_preference_vector, dtype=np.float32)
        perf_vec = np.array(embedding, dtype=np.float32)

        # 정규화 확인
        user_norm = np.linalg.norm(user_vec)
        perf_norm = np.linalg.norm(perf_vec)

        if user_norm == 0 or perf_norm == 0:
            return 0.0

        # 코사인 유사도 계산
        similarity = np.dot(user_vec, perf_vec) / (user_norm * perf_norm)

        # -1~1 범위를 0~1로 변환
        score = (similarity + 1) / 2

        return score

    except Exception:
        return 0.0
```

## ⚠️ 주의사항 및 제약사항

### 1. 데이터 요구사항
- **필수**: Performance 모델에 `embedding` 필드 존재
- 온보딩 후보 공연은 임베딩이 있는 것만 표시됨
- 임베딩이 없는 공연은 추천에서 제외됨

### 2. 성능 고려사항
- 임베딩 벡터는 1536차원 × float32 = 6KB
- UserPreference는 JSONField에 저장 (PostgreSQL JSONB 권장)
- 추천 시 코사인 유사도 계산은 O(1536) = 상수 시간

### 3. 에러 처리
```python
# 온보딩 미완료 시 추천 점수
if not user_preference_vector:
    f7_score = 0.0  # 임베딩 점수 0, 다른 5개 요인만 사용
```

### 4. 보안
- 온보딩 API는 `IsAuthenticated` 권한 필수
- 타 사용자의 신호 조작 방지 (user=request.user 강제)
