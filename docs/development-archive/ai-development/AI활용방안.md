## 개요

### 목적
OpenAI의 ChatGPT API와 워드 임베딩 기술을 활용하여 공연 추천 시스템의 **지능성과 사용자 경험을 향상**시킵니다.

### 핵심 가치
- **의미 기반 이해**: 키워드 매칭을 넘어 문맥과 의미를 이해
- **자연스러운 대화**: 사용자와 자연어로 소통
- **개인화**: 사용자의 취향을 깊이 있게 분석
- **자동화**: 반복적인 작업을 AI가 대신 처리

---

## 기술 스택

### OpenAI API
- **GPT-4o-mini**: 텍스트 생성, 대화, 분석
- **text-embedding-3-small**: 텍스트 임베딩 (의미 벡터화)

### 주요 기술
- **임베딩 (Embeddings)**: 텍스트를 고차원 벡터로 변환
- **코사인 유사도 (Cosine Similarity)**: 의미적 유사성 측정
- **프롬프트 엔지니어링**: AI에게 적절한 지시사항 전달

## 주요 기능 아이디어

### 1️⃣ 의미 기반 공연 검색 (Semantic Search)

#### 개념
사용자가 자연어로 검색하면 의미적으로 유사한 공연을 추천합니다.

#### 사용 예시
| 검색어 | 기존 키워드 검색 | AI 의미 검색 |
|--------|------------------|--------------|
| "감동적인 사랑 이야기" | ❌ 결과 없음 | ✅ 로맨틱 뮤지컬, 사랑 테마 연극 |
| "웃긴 공연" | ❌ 정확히 "웃긴" 포함된 것만 | ✅ 코미디, 개그, 유쾌한 공연 모두 |
| "가족이랑 볼만한" | ❌ "가족" 키워드만 | ✅ 전연령, 어린이 환영 공연 |

#### 동작 방식
1. 사용자 검색어를 임베딩 벡터로 변환
2. 모든 공연의 설명(제목, 장르, 줄거리)을 임베딩
3. 코사인 유사도로 가장 비슷한 공연 상위 N개 추출

#### 장점
- **동의어 인식**: "재미있는" = "웃긴" = "유쾌한"
- **문맥 이해**: "아이와 함께" → 가족 친화적 공연
- **정확도 향상**: 키워드 누락으로 인한 검색 실패 감소

### 2️⃣ AI 공연 큐레이터 (Personalized Curator)

#### 개념
ChatGPT가 전문 큐레이터처럼 사용자의 취향을 분석하고, 개인화된 추천과 함께 **왜 추천하는지 이유를 자연스럽게 설명**합니다.

#### 추천 예시
```
🎭 AI 큐레이터의 추천

안녕하세요! 최근 활동 기록을 분석해봤어요 😊

1. 뮤지컬 "레베카" ⭐⭐⭐⭐⭐
   💡 이유: 조승우 배우님을 좋아하시는 것 같아요! 이 작품은
   미스터리와 로맨스가 잘 어우러져 있어 감동적인 스토리를
   좋아하시는 당신에게 딱입니다. 강남 블루스퀘어에서 공연 중이라
   접근성도 좋아요!

2. 연극 "햄릿" ⭐⭐⭐⭐
   💡 이유: 최근 클래식 연극을 많이 보셨더라고요. 셰익스피어의
   대표작으로 깊이 있는 스토리와 철학적 메시지가 인상적일 거예요.

3. 뮤지컬 "시카고" ⭐⭐⭐⭐
   💡 이유: 재즈와 블루스를 좋아하신다면 이 작품의 음악이
   환상적일 거예요. 화려한 안무와 함께 짜릿한 에너지를 느낄 수 있어요!
```

#### 분석 요소
- 선호 장르
- 좋아하는 배우/제작진
- 거주 지역 (접근성)
- 최근 찜한 공연 패턴
- 작성한 리뷰의 감정 톤

#### 차별점
- **단순 점수가 아닌 스토리텔링**: 추천 이유를 사람처럼 설명
- **감성적 연결**: "이 공연은 0.85점입니다" → "당신의 취향에 딱이에요!"
- **신뢰 구축**: 왜 추천하는지 이해하면 수용도 ↑

### 3️⃣ 공연 리뷰 감정 분석 & 요약

#### 개념
수십, 수백 개의 리뷰를 AI가 자동으로 분석하여 **핵심만 3줄로 요약**합니다.

#### Before (기존)
```
리뷰 100개를 일일이 읽어야 함...
- "배우 연기가 좋았어요"
- "음향이 너무 커서 귀가 아팠어요"
- "스토리가 감동적이었습니다"
- "무대 장치가 화려해요"
- ... (96개 더)
```

#### After (AI 요약)
```
📊 리뷰 요약 (AI 분석 - 총 100개 리뷰)

✅ 긍정 포인트:
   • 배우들의 연기력과 무대 연출이 훌륭하다는 평이 압도적 (85%)
   • 스토리가 감동적이고 몰입감이 뛰어나다는 평가 (78%)

❌ 개선 포인트:
   • 일부 관객은 음향이 다소 크다고 느꼈음 (23%)
   • 러닝타임이 길어 지루할 수 있다는 의견 (15%)

⭐ 종합 평가:
   전반적으로 매우 만족스러운 공연으로 평가받고 있습니다.
   특히 연기와 연출에서 높은 점수를 받았으며, 감동적인
   스토리를 원하는 분들께 강력 추천합니다.
```

#### 감정 분석 추가
- **긍정 리뷰**: 70% (70개)
- **중립 리뷰**: 20% (20개)
- **부정 리뷰**: 10% (10개)

#### 활용 효과
- **시간 절약**: 100개 리뷰 읽기 30분 → 요약 읽기 1분
- **의사결정 지원**: 핵심만 빠르게 파악
- **신뢰도 향상**: 다수의 의견을 종합적으로 제시

### 4️⃣ 유사 공연 추천 (Similar Performances)

#### 개념
현재 보고 있는 공연과 **스토리, 분위기, 장르가 비슷한** 다른 공연을 추천합니다.

#### 추천 예시
```
🎭 "뮤지컬 레베카"를 보고 계신다면...

이런 공연도 좋아하실 거예요!

1. 뮤지컬 "엘리자벳" (유사도: 92%)
   → 유럽 왕실을 배경으로 한 로맨틱 비극. 레베카와 비슷한
      감성과 클래식한 분위기

2. 연극 "제인 에어" (유사도: 88%)
   → 고딕 로맨스의 고전. 미스터리와 사랑이 얽힌 스토리

3. 뮤지컬 "지킬 앤 하이드" (유사도: 85%)
   → 어두운 분위기와 강렬한 드라마, 심리적 갈등이 돋보임
```

#### 분석 기준
- **장르 유사성**: 뮤지컬 ↔ 뮤지컬, 연극 ↔ 연극
- **스토리 테마**: 로맨스, 미스터리, 코미디 등
- **분위기**: 감동적, 경쾌함, 어두움, 유쾌함
- **시대 배경**: 현대, 고전, 판타지 등
- **감정 톤**: 슬픔, 기쁨, 긴장감, 희망

#### 차별점
- 기존 협업 필터링: "A를 좋아한 사람은 B도 좋아함" (통계)
- AI 유사도: "A와 B의 **스토리와 분위기가 실제로 비슷함**" (의미)

### 5️⃣ 대화형 공연 추천 챗봇

#### 개념
사용자와 자연스럽게 **대화하며 취향을 파악**하고, 최적의 공연을 찾아줍니다.

#### 대화 시나리오 예시

**시나리오 1: 가족 추천**
```
🤖 봇: 안녕하세요! 어떤 공연을 찾고 계신가요?

👤 사용자: 주말에 가족이랑 볼만한 거 있을까요?

🤖 봇: 좋아요! 함께 가실 가족 구성원의 연령대가 어떻게 되시나요?

👤 사용자: 초등학생 아이 둘이요

🤖 봇: 아이들과 함께라면 "뮤지컬 라이온킹"을 추천드립니다!
      디즈니 애니메이션 원작이라 아이들도 재미있게 볼 수 있고,
      어른들도 감동적인 스토리와 웅장한 음악을 즐길 수 있어요.

      혹시 선호하시는 지역이나 날짜가 있으신가요?

👤 사용자: 강남 쪽이 좋아요

🤖 봇: 강남 블루스퀘어에서 공연 중입니다!
      📅 공연 일정: 2025-01-15 ~ 2025-03-31
      🎫 예매하기: [링크]
```

**시나리오 2: 데이트 추천**
```
🤖 봇: 어떤 공연을 찾고 계신가요?

👤 사용자: 여자친구랑 데이트하려고요

🤖 봇: 로맨틱한 분위기를 원하시나요, 아니면 재미있는 공연을 원하시나요?

👤 사용자: 둘 다요 ㅋㅋ

🤖 봇: 욕심쟁이시네요! 😄 그렇다면 "뮤지컬 시카고"는 어떠세요?
      재즈와 화려한 춤으로 재미있으면서도, 로맨틱한 순간들이
      있어서 데이트에 딱입니다!
```

#### 특징
- **자연스러운 대화**: 딱딱한 폼 입력 대신 채팅처럼
- **점진적 정보 수집**: 한 번에 모든 걸 물어보지 않고 대화로 파악
- **유연한 대응**: 예상치 못한 질문에도 답변 가능
- **감정 표현**: 이모지, 친근한 말투로 친밀감 형성

### 6️⃣ 자동 태그 생성 & 분류

#### 개념
공연 소개글을 읽고 AI가 자동으로 **분위기, 추천 대상, 특징을 태그로 생성**합니다.

#### 태그 예시

**뮤지컬 "레베카"**
```
자동 생성 태그:
#감동적인 #로맨틱 #미스터리 #고딕풍 #어른추천
#데이트추천 #몰입감높음 #클래식뮤지컬 #심리드라마
```

**뮤지컬 "맘마미아"**
```
자동 생성 태그:
#유쾌한 #신나는 #가족추천 #ABBA음악 #코미디
#밝은분위기 #여름느낌 #그리스배경 #웨딩스토리
```

**연극 "햄릿"**
```
자동 생성 태그:
#고전명작 #셰익스피어 #철학적 #비극 #심오한
#어른추천 #문학적 #성찰 #복수극
```

#### 활용 방안
- **검색 필터링**: 태그로 공연 필터링
- **추천 알고리즘**: 태그 매칭으로 유사 공연 찾기
- **UI/UX**: 한눈에 공연 특징 파악

#### 태그 카테고리
- **분위기**: 감동적인, 유쾌한, 긴장감 넘치는, 잔잔한
- **추천 대상**: 가족추천, 데이트추천, 어른추천, 어린이환영
- **장르 특징**: 코미디, 로맨스, 미스터리, 액션
- **감정**: 눈물주의, 웃음폭발, 설렘, 카타르시스
- **음악**: 재즈, 클래식, 팝, 발라드

### 7️⃣ 리뷰 작성 도우미

#### 개념
사용자가 **간단한 키워드나 메모만 입력**하면 AI가 자연스러운 리뷰 문장으로 완성해줍니다.

#### 사용 흐름

**Step 1: 간단한 메모 입력**
```
사용자 입력:
- 배우 연기 좋음
- 스토리 감동
- 음향 좀 큼
- 별점: 4.5
```

**Step 2: AI가 완성된 리뷰 제안**
```
AI 생성 리뷰:

"뮤지컬 레베카" 정말 인상 깊었습니다! ⭐⭐⭐⭐☆

배우들의 연기력이 정말 뛰어났어요. 특히 주인공의 감정 표현이
너무 섬세해서 몰입감이 대단했습니다. 스토리 자체도 매우 감동적이고
여운이 오래 남는 작품이었어요.

다만 음향이 조금 크게 느껴져서 귀가 살짝 피로했던 점은 아쉬웠습니다.
그래도 전반적으로 매우 만족스러운 공연이었고, 감동적인 뮤지컬을
좋아하시는 분들께 강력 추천드립니다!
```

**Step 3: 수정 및 게시**
```
사용자가 원하면 문장 수정 후 게시
또는 그대로 사용
```

#### 장점
- **리뷰 작성 장벽 낮춤**: "뭐라고 써야 하지?" 고민 해결
- **풍부한 표현**: 단순 메모 → 자연스러운 문장
- **시간 절약**: 5분 고민 → 10초 생성
- **참여율 증가**: 리뷰 작성이 쉬워져 더 많은 사용자 참여

### 8️⃣ 취향 프로필 자동 생성

#### 개념
사용자의 **찜하기, 리뷰, 조회 기록**을 AI가 분석하여 취향을 자동으로 프로파일링합니다.

#### 프로필 예시

**사용자 A (감성파)**
```
🎭 당신의 공연 취향 프로필

당신은 감성적이고 깊이 있는 스토리를 선호하는 "감성파" 관객입니다.

📊 분석 결과:
• 선호 장르: 뮤지컬 (70%), 연극 (25%), 오페라 (5%)
• 선호 테마: 로맨스, 휴먼드라마, 성장 스토리
• 선호 분위기: 감동적이고 여운이 긴 작품
• 좋아하는 요소: 섬세한 연기, 아름다운 음악, 철학적 메시지

💡 추천 키워드:
#감동적인 #여운있는 #휴먼드라마 #클래식뮤지컬 #심금을울리는
```

**사용자 B (에너지파)**
```
🎭 당신의 공연 취향 프로필

당신은 에너지 넘치고 재미있는 공연을 즐기는 "에너지파" 관객입니다.

📊 분석 결과:
• 선호 장르: 뮤지컬 (60%), 코미디 (30%), 넌버벌 (10%)
• 선호 테마: 코미디, 액션, 가벼운 로맨스
• 선호 분위기: 경쾌하고 신나는 작품
• 좋아하는 요소: 화려한 무대, 댄스, 유머

💡 추천 키워드:
#신나는 #코미디 #밝은분위기 #화려한무대 #액션넘치는
```

#### 활용 방안
- **맞춤 추천 강화**: 프로필 기반 추천 정확도 향상
- **마이페이지 표시**: "나는 어떤 관객인가?" 정체성 제공
- **소셜 기능**: 비슷한 취향의 사용자 연결
- **자기 발견**: "내가 이런 취향이었구나!" 인사이트 제공

### 9️⃣ 스마트 Q&A (공연 관련 질문 답변)

#### 개념
공연 정보에 대해 사용자가 **자유롭게 질문**하면 AI가 답변합니다.

#### 질문 예시

**질문 1: 드레스코드**
```
👤 질문: 뮤지컬 오페라의 유령 볼 때 뭐 입고 가야 하나요?

🤖 답변: 오페라의 유령은 고급스러운 분위기의 공연이지만,
         한국에서는 드레스코드가 엄격하지 않습니다.
         스마트 캐주얼 정도면 충분하고, 편안한 복장도 괜찮아요.
         다만 너무 캐주얼한 반바지나 슬리퍼는 피하는 것이 좋습니다.
```

**질문 2: 주차 정보**
```
👤 질문: 블루스퀘어 주차장 있나요?

🤖 답변: 네! 블루스퀘어에는 지하 주차장이 있습니다.
         공연 관람객은 3시간 무료 주차가 가능하며,
         주차장 입구는 건물 B1층에 위치해 있습니다.
```

**질문 3: 관람 연령**
```
👤 질문: 7살 아이가 봐도 될까요?

🤖 답변: 이 공연은 8세 이상 관람가입니다. 7살이라면
         공식적으로는 입장이 제한될 수 있어요.
         만약 아이가 90분 동안 집중할 수 있다면 극장에
         문의해보시는 것을 추천드립니다!
```

#### 장점
- **정보 접근성 향상**: FAQ 페이지 찾을 필요 없음
- **자연스러운 대화**: 딱딱한 Q&A 리스트 대신 편하게 질문
- **맥락 이해**: "거기 주차장 있어?" → "블루스퀘어" 자동 인식

### 🔟 공연 추천 이유 설명 (Explainable AI)

#### 개념
추천 알고리즘이 **왜 이 공연을 추천했는지** AI가 자연어로 설명합니다.

#### 기존 추천 (점수만)
```
추천 공연: 뮤지컬 레베카
추천 점수: 0.85
```
→ 사용자: "왜 추천된 거지? 점수가 뭔 의미야?"

#### AI 설명 추가
```
추천 공연: 뮤지컬 레베카
추천 점수: 0.85

📝 추천 이유:
1. 위치 (35점): 강남구에 거주하시는데, 이 공연은 강남 블루스퀘어에서
   진행되어 접근성이 매우 좋습니다.

2. 취향 매칭 (25점): 선호 장르가 '뮤지컬'과 '로맨스'인데,
   레베카는 로맨틱 미스터리 뮤지컬로 딱 맞습니다.

3. 최근 관심 (15점): 최근에 '엘리자벳'을 찜하셨는데,
   레베카도 유럽 배경의 클래식 뮤지컬이라 비슷한 감성입니다.

4. 인기도 (10점): 현재 박스오피스 3위로 많은 관객들이
   좋아하는 검증된 작품입니다.
```

#### 효과
- **신뢰 구축**: 추천 근거를 알면 믿음 증가
- **학습 효과**: "내 취향을 이렇게 분석하는구나"
- **피드백 가능**: "위치는 상관없어요" → 가중치 조정

## 기술적 고려사항

### 임베딩 DB 구축

#### 필요성
- 모든 공연/리뷰를 매번 임베딩하면 비용 과다
- 임베딩 결과를 DB에 저장하여 재사용

#### 구조
```
Performance 모델에 추가:
- embedding_vector: JSONField (1536 차원)
- embedding_updated_at: DateTimeField

주기적 업데이트:
- 새로운 공연 추가 시
- 공연 정보 수정 시
- 월 1회 배치 작업
```

### 캐싱 전략

#### API 응답 캐싱
- 동일한 질문/검색어에 대한 응답 캐싱 (TTL: 1시간)
- Redis 활용

#### 임베딩 캐싱
- 공연 임베딩: 변경 시에만 재계산
- 검색어 임베딩: 인기 검색어는 캐싱

### 비용 최적화

#### Batch Processing
- 여러 공연을 한 번에 임베딩 (API 호출 횟수 감소)

#### 모델 선택
- 단순 작업: gpt-4o-mini (저렴)
- 복잡한 작업: gpt-4o (고급)

#### 프롬프트 최적화
- 짧고 명확한 프롬프트로 토큰 수 절감
- System 프롬프트 재사용
