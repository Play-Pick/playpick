# AI 임베딩 전략 테스트

이 디렉토리는 공연 데이터 임베딩 생성을 위한 3가지 전략을 테스트하는 스크립트를 포함합니다.

## 📁 파일 구조

```
aitest/
├── README.md                        # 이 파일
├── test_strategy_1_minimal.py      # 전략 1: 미니멀
├── test_strategy_2_standard.py     # 전략 2: 스탠다드 (추천)
├── test_strategy_3_maximum.py      # 전략 3: 맥시멈
└── compare_all.py                   # 3가지 전략 비교
```

## 🎯 3가지 전략 비교

| 전략 | 포함 필드 | 평균 토큰 | 60,000개 비용 | 특징 |
|------|----------|-----------|--------------|------|
| **1. Minimal** | 제목, 장르, 출연진 | ~30 | $0.036 | 빠르고 경제적 |
| **2. Standard** | + 지역, 공연장, 줄거리(200자) | ~100 | $0.12 | 품질/비용 균형 ✨ |
| **3. Maximum** | + 모든 상세정보, 줄거리 전체 | ~300 | $0.36 | 최고 품질 |

## 🚀 사용 방법

### 사전 준비

1. OpenAI API 키 설정
```bash
# back/.env 파일에 추가
OPENAI_API_KEY=sk-proj-your-api-key-here
```

2. 가상환경 활성화
```bash
cd back
source ../.venv/bin/activate  # Linux/Mac
..\\.venv\\Scripts\\activate   # Windows
```

### 개별 전략 테스트

#### 전략 1: 미니멀
```bash
python aitest/test_strategy_1_minimal.py
```


## 📊 실제 임베딩 생성 테스트

각 스크립트 실행 후 "y" 입력 시 실제 OpenAI API를 호출하여 임베딩을 생성합니다.

```
실제 임베딩 생성 테스트를 진행하시겠습니까? (y/n): y

첫 번째 공연으로 임베딩 생성 중...
✅ 임베딩 생성 성공!
   - 벡터 차원: 1536
   - 벡터 샘플: [0.023, -0.045, 0.067, ...]
   - 실제 사용 토큰: 95 tokens
   - 실제 비용: $0.000019
```

## ⚠️ 주의사항

1. **API 키 필요**: OpenAI API 키가 `.env` 파일에 설정되어 있어야 합니다.
2. **비용 발생**: 실제 임베딩 생성 테스트 시 소량의 비용이 발생합니다 (공연 1개당 ~$0.00002).
3. **Rate Limit**: 무료 티어는 분당 3회로 제한되므로 주의하세요.
