# 찜하기 버튼 구현 완료 가이드

## 📋 구현 개요

공연 상세 페이지([PerformanceDetailView.vue](../front/src/views/PerformanceDetailView.vue))의 헤더 섹션에 찜하기 버튼을 추가했습니다.

사용자가 버튼을 클릭하면:
1. 백엔드 API로 찜하기/취소 요청 전송
2. DB의 ManyToMany 관계 업데이트
3. 추천 시스템용 UserLog 자동 생성
4. UI에 실시간 반영 (하트 아이콘, 찜 개수)

#### Backend 처리

**ViewSet Action** ([api_views.py:198-228](../back/performances/api_views.py#L198-L228)):
```python
@action(detail=True, methods=['post'], permission_classes=[IsAuthenticated])
def like(self, request, pk=None):
    """
    공연 찜하기/취소 토글
    POST /api/performances/{mt20id}/like/
    """
    performance = self.get_object()
    user = request.user

    if user in performance.like_users.all():
        # 찜 취소
        performance.like_users.remove(user)
        is_liked = False
    else:
        # 찜하기
        performance.like_users.add(user)
        is_liked = True

        # 추천 시스템 로그 저장
        from recommendations.models import UserLog
        UserLog.objects.create(
            user=user,
            performance=performance,
            action_type='like'
        )

    return Response({
        'success': True,
        'is_liked': is_liked,
        'like_count': performance.like_users.count()
    })
```

**핵심 로직**:
1. **토글 방식**: 이미 찜했으면 취소, 아니면 추가
2. **ManyToMany 관계**: `performance.like_users.add(user)` / `.remove(user)`
3. **UserLog 생성**: 찜하기 시에만 자동 생성 (추천 시스템용)
4. **응답**: 현재 상태(`is_liked`)와 전체 찜 개수(`like_count`) 반환

## 🧪 테스트 시나리오

### 1. 기본 동작 테스트

1. **로그인하지 않은 상태**:
   - 버튼 클릭 → "로그인이 필요합니다." 알림
   - 찜 상태 변경 안 됨

2. **로그인한 상태 - 찜하기**:
   - 빈 하트 버튼 클릭
   - 로딩 중 버튼 비활성화
   - 성공 시 채워진 하트로 변경
   - 찜 개수 1 증가

3. **로그인한 상태 - 찜 취소**:
   - 채워진 하트 버튼 클릭
   - 빈 하트로 변경
   - 찜 개수 1 감소

### 2. DB 검증

**MySQL 확인**:
```sql
-- 찜하기 관계 조회
SELECT * FROM performances_performance_like_users
WHERE performance_id = 'PF264404' AND user_id = 1;

WHERE performance_id = 'PF264404'
  AND user_id = 1
```
