## 📡 API 명세

### 공연 찜하기/취소 토글

**Endpoint**: `POST /api/performances/{mt20id}/like/`

**Request Headers**:
```
Authorization: Bearer {access_token}
```

**Response (200 OK)**:
```json
{
  "success": true,
  "is_liked": true,
  "like_count": 42
}
```

**동작**:
1. 이미 찜한 공연이면 → 찜 취소 (`is_liked: false`)
2. 찜하지 않은 공연이면 → 찜하기 (`is_liked: true`) + UserLog 자동 저장

### 2. PerformanceCard 컴포넌트에서 사용

```vue
<template>
  <div class="performance-card">
    <img :src="performance.poster" />
    <h3>{{ performance.prfnm }}</h3>

    <!-- 찜하기 아이콘 버튼 -->
    <button
      @click.prevent="handleLike"
      class="like-icon-button"
      :class="{ active: performance.is_liked }"
    >
      <i :class="performance.is_liked ? 'fas fa-heart' : 'far fa-heart'"></i>
    </button>
  </div>
</template>

<script setup>
import { useUserTracking } from '@/composables/useUserTracking'

const props = defineProps({
  performance: {
    type: Object,
    required: true
  }
})

const emit = defineEmits(['update'])

const { toggleLike, likeLoading } = useUserTracking()

const handleLike = async () => {
  try {
    const result = await toggleLike(props.performance.mt20id)

    // 부모 컴포넌트에 업데이트 알림
    emit('update', {
      mt20id: props.performance.mt20id,
      is_liked: result.is_liked,
      like_count: result.like_count
    })
  } catch (err) {
    console.error('찜하기 실패:', err)
  }
}
</script>
```

### 3. Pinia Store로 관리 (선택사항)

```javascript
// stores/performanceStore.js
import { defineStore } from 'pinia'
import performanceAPI from '@/api/performances'

export const usePerformanceStore = defineStore('performance', {
  state: () => ({
    currentPerformance: null,
    performances: []
  }),

  actions: {
    async toggleLike(performanceId) {
      const response = await performanceAPI.toggleLike(performanceId)
      const { is_liked, like_count } = response.data

      // currentPerformance 업데이트
      if (this.currentPerformance?.mt20id === performanceId) {
        this.currentPerformance.is_liked = is_liked
        this.currentPerformance.like_count = like_count
      }

      // performances 목록 업데이트
      const index = this.performances.findIndex(p => p.mt20id === performanceId)
      if (index !== -1) {
        this.performances[index].is_liked = is_liked
        this.performances[index].like_count = like_count
      }

      return response.data
    }
  }
})
```

## 🎯 추천 시스템 연동

### 찜하기 → 추천 알고리즘 반영

1. **찜하기 시**: UserLog에 `action_type='like'` 자동 저장
2. **추천 점수 계산**:
   - $f_1$ (클릭/관심): 'like' 행동은 3점 (view: 1점, search: 2점보다 높음)
   - $f_6$ (협업 필터링): 찜한 공연과 유사한 공연 추천

```python
# recommendations/engine.py
ACTION_SCORES = {
    'view': 1,
    'like': 3,    # ← 찜하기는 높은 점수!
    'search': 2
}
```

## 💡 주의사항

1. **인증 필수**: 찜하기는 로그인한 사용자만 가능
2. **중복 방지**: ManyToMany 관계로 자동 중복 방지
3. **로그 저장**: 찜하기 시에만 로그 저장 (취소 시는 저장 안 함)
4. **성능**: `is_liked` 계산 시 DB 쿼리 발생 → 목록 조회 시 prefetch 권장

```python
# 성능 최적화 예시
queryset = Performance.objects.prefetch_related('like_users')
```
