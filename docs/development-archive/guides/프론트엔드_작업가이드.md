# 🎨 프론트엔드 추천 시스템 개발 가이드

## 📋 백엔드 API 엔드포인트 (예정)

백엔드 팀이 제공할 API 목록:

### 1. 사용자 행동 로깅 API
```http
POST /api/recommendations/log/
Content-Type: application/json
Authorization: Bearer {access_token}

{
  "performance_id": "PF264404",
  "action_type": "view"  // 'view', 'like', 'search'
}

Response:
{
  "success": true,
  "message": "로그 저장 완료"
}
```

### 2. 개인화 추천 목록 API
```http
GET /api/recommendations/list/
Authorization: Bearer {access_token}

Response:
{
  "success": true,
  "recommendations": [
    {
      "mt20id": "PF264404",
      "prfnm": "태양의서커스, 쿠자",
      "poster": "http://...",
      "genrenm": "서커스/마술",
      "score": 0.85,
      "reason": "location",  // 추천 사유 코드
      "reason_text": "🏠 강남구 근처에서 공연해요!"
    },
    // ... 최대 10개
  ]
}
```

**추천 사유 코드 (reason):**
- `location`: 위치 기반 추천
- `actor`: 선호 배우 출연
- `genre`: 선호 장르 일치
- `popular`: 대중성 높음
- `collaborative`: 유사 사용자 기반
- `recency`: 곧 시작하는 공연

## 🎯 Phase 1: 사용자 행동 추적 (D-4)

### 작업 1: useUserTracking Composable 생성

**파일:** `front/src/composables/useUserTracking.js`

```javascript
import apiClient from '@/api/axios'

export const useUserTracking = () => {
  /**
   * 사용자 행동 로깅
   * @param {string} performanceId - 공연 ID
   * @param {string} actionType - 'view', 'like', 'search'
   */
  const logAction = async (performanceId, actionType) => {
    try {
      await apiClient.post('/recommendations/log/', {
        performance_id: performanceId,
        action_type: actionType
      })
      console.log(`✅ 로그 전송: ${actionType} - ${performanceId}`)
    } catch (error) {
      // 로깅 실패는 사용자 경험에 영향 없음 (조용히 실패)
      console.warn('로그 전송 실패:', error)
    }
  }

  return {
    logAction
  }
}
```

### 작업 5: 추천 Store 생성 (Optional)

**파일:** `front/src/stores/recommendationStore.js`

```javascript
import { defineStore } from 'pinia'
import { ref } from 'vue'
import recommendationAPI from '@/api/recommendations'

export const useRecommendationStore = defineStore('recommendation', () => {
  const recommendations = ref([])
  const loading = ref(false)
  const error = ref(null)

  const fetchRecommendations = async () => {
    loading.value = true
    error.value = null
    try {
      const response = await recommendationAPI.getRecommendations()
      recommendations.value = response.data.recommendations || []
      return response.data
    } catch (err) {
      error.value = err.message
      throw err
    } finally {
      loading.value = false
    }
  }

  return {
    recommendations,
    loading,
    error,
    fetchRecommendations
  }
})
```

## 🌟 Phase 3: 추가 기능 (Optional, D-2)

### 작업 8: 온보딩 페이지 (회원가입 시 취향 수집)

**파일:** `front/src/views/OnboardingView.vue`

```vue
<template>
  <div class="onboarding">
    <h1>🎭 취향 설정</h1>
    <p class="subtitle">맞춤 공연 추천을 위해 알려주세요!</p>

    <!-- Step 1: 선호 장르 -->
    <div class="section">
      <h3>어떤 공연을 좋아하세요? (복수 선택 가능)</h3>
      <div class="genre-chips">
        <button
          v-for="genre in genres"
          :key="genre"
          @click="toggleGenre(genre)"
          class="chip"
          :class="{ selected: selectedGenres.includes(genre) }"
        >
          {{ genre }}
        </button>
      </div>
    </div>

    <!-- Step 2: 선호 배우 -->
    <div class="section">
      <h3>좋아하는 배우가 있나요?</h3>
      <input
        v-model="actorInput"
        @keyup.enter="addActor"
        placeholder="배우 이름을 입력하고 Enter"
        class="actor-input"
      />
      <div class="actor-tags">
        <span v-for="actor in selectedActors" :key="actor" class="tag">
          {{ actor }}
          <button @click="removeActor(actor)">×</button>
        </span>
      </div>
    </div>

    <!-- Step 3: 위치 -->
    <div class="section">
      <h3>주로 어디에서 관람하시나요?</h3>
      <select v-model="selectedRegion" class="region-select">
        <option value="">선택하세요</option>
        <option value="강남구">강남구</option>
        <option value="종로구">종로구</option>
        <option value="중구">중구</option>
        <option value="마포구">마포구</option>
        <option value="송파구">송파구</option>
        <!-- 더 많은 구 추가 가능 -->
      </select>
    </div>

    <!-- 완료 버튼 -->
    <div class="actions">
      <button @click="skip" class="skip-button">건너뛰기</button>
      <button @click="savePreferences" class="save-button">완료</button>
    </div>
  </div>
</template>

<script setup>
import { ref } from 'vue'
import { useRouter } from 'vue-router'
import { useAuthStore } from '@/stores/authStore'
import apiClient from '@/api/axios'

const router = useRouter()
const authStore = useAuthStore()

const genres = ['뮤지컬', '연극', '클래식', '오페라', '무용', '대중음악', '서커스/마술']
const selectedGenres = ref([])
const selectedActors = ref([])
const actorInput = ref('')
const selectedRegion = ref('')

const toggleGenre = (genre) => {
  const index = selectedGenres.value.indexOf(genre)
  if (index > -1) {
    selectedGenres.value.splice(index, 1)
  } else {
    selectedGenres.value.push(genre)
  }
}

const addActor = () => {
  if (actorInput.value.trim() && !selectedActors.value.includes(actorInput.value.trim())) {
    selectedActors.value.push(actorInput.value.trim())
    actorInput.value = ''
  }
}

const removeActor = (actor) => {
  const index = selectedActors.value.indexOf(actor)
  if (index > -1) {
    selectedActors.value.splice(index, 1)
  }
}

const savePreferences = async () => {
  try {
    // User 정보 업데이트
    await apiClient.patch('/accounts/profile/', {
      preference_tags: selectedGenres.value,
      favorite_actors: selectedActors.value,
      region_gu: selectedRegion.value
    })

    alert('취향 설정이 완료되었습니다!')
    router.push('/')
  } catch (error) {
    console.error('저장 실패:', error)
    alert('저장에 실패했습니다.')
  }
}

const skip = () => {
  router.push('/')
}
</script>

<style scoped>
/* 스타일은 생략 - 위의 RecommendationCard와 유사한 스타일 적용 */
</style>
```
