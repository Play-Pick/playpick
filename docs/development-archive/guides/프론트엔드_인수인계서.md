## 1. 프로젝트 개요

### 1.1 프로젝트 설명
PlayPick은 KOPIS API를 활용한 공연 정보 제공 및 추천 플랫폼입니다.
사용자는 공연 정보를 조회하고, 찜하기, 리뷰 작성, 커뮤니티 활동을 할 수 있습니다.

### 1.2 주요 기능
- 🎭 **공연 정보**: KOPIS API 기반 실시간 공연 정보 제공
- 📊 **랭킹 시스템**: 전체/장르별 실시간 박스오피스 랭킹
- 💝 **개인화**: 찜하기, 조회 기록 기반 추천
- 📝 **커뮤니티**: 관람후기, 기대평, Q&A 작성
- 🌓 **다크모드**: 전체 페이지 다크모드 지원
- 📱 **반응형**: 모바일/태블릿/데스크톱 대응

### 4.3 캐러셀/슬라이더 구현

#### 구현된 캐러셀들
1. **HighlightCarousel**: 히어로 배너 (자동 재생, 인디케이터)

#### 페이지 기반 캐러셀 패턴
```vue
<template>
  <div class="carousel-wrapper">
    <!-- 좌측 화살표 -->
    <button v-if="canGoPrev" @click="prevPage">
      <i class="fas fa-chevron-left"></i>
    </button>

    <!-- 트랙 -->
    <div class="performances-track">
      <div
        class="performances-wrapper"
        :style="{ transform: `translateX(${translateX}%)` }"
      >
        <div v-for="item in items" :key="item.id">
          {{ item }}
        </div>
      </div>
    </div>

    <!-- 우측 화살표 -->
    <button v-if="canGoNext" @click="nextPage">
      <i class="fas fa-chevron-right"></i>
    </button>
  </div>
</template>

<script setup>
const currentPage = ref(0)
const itemsPerPage = ref(5)

const totalPages = computed(() =>
  Math.ceil(items.value.length / itemsPerPage.value)
)

const translateX = computed(() => -(currentPage.value * 100))

const canGoPrev = computed(() => currentPage.value > 0)
const canGoNext = computed(() => currentPage.value < totalPages.value - 1)

const prevPage = () => {
  if (canGoPrev.value) currentPage.value--
}

const nextPage = () => {
  if (canGoNext.value) currentPage.value++
}
</script>

<style scoped>
.performances-track {
  overflow: hidden;
  width: 100%;
}

.performances-wrapper {
  display: flex;
  gap: 1.5rem;
  transition: transform 0.5s cubic-bezier(0.4, 0, 0.2, 1);
}
</style>
```

### 4.5 별점 시스템 (0.5 단위)

```vue
<template>
  <div class="star-rating">
    <div
      v-for="n in 5"
      :key="n"
      class="star-wrapper"
      @mousemove="handleStarHover($event, n)"
      @mouseleave="hoverRating = 0"
      @click="handleStarClick($event, n)"
    >
      <i
        class="fas fa-star star-full"
        :class="{ active: n <= (hoverRating || rating) }"
      ></i>
      <i
        class="fas fa-star-half-alt star-half"
        :class="{ active: n - 0.5 === (hoverRating || rating) }"
      ></i>
    </div>
    <span class="rating-text">{{ rating }}점</span>
  </div>
</template>

<script setup>
const rating = ref(5)
const hoverRating = ref(0)

const handleStarHover = (event, starNumber) => {
  const target = event.currentTarget
  const rect = target.getBoundingClientRect()
  const x = event.clientX - rect.left
  const halfWidth = rect.width / 2

  hoverRating.value = x < halfWidth ? starNumber - 0.5 : starNumber
}

const handleStarClick = (event, starNumber) => {
  const target = event.currentTarget
  const rect = target.getBoundingClientRect()
  const x = event.clientX - rect.left
  const halfWidth = rect.width / 2

  rating.value = x < halfWidth ? starNumber - 0.5 : starNumber
}
</script>

<style scoped>
.star-wrapper {
  position: relative;
  display: inline-block;
  cursor: pointer;
}

.star-full {
  color: #d1d5db;
}

.star-full.active {
  color: #fbbf24;
}

.star-half {
  position: absolute;
  left: 0;
  top: 0;
  color: transparent;
  overflow: hidden;
  width: 50%;
}

.star-half.active {
  color: #fbbf24;
}
</style>
```

## 8. API 연동

### 8.1 Axios 설정

```javascript
// front/src/api/axios.js
import axios from 'axios'

const apiClient = axios.create({
  baseURL: 'http://127.0.0.1:8000/api/v1',
  headers: {
    'Content-Type': 'application/json'
  }
})

// 요청 인터셉터 (토큰 자동 추가)
apiClient.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('access_token')
    if (token) {
      config.headers.Authorization = `Bearer ${token}`
    }
    return config
  },
  (error) => Promise.reject(error)
)

// 응답 인터셉터 (401 처리)
apiClient.interceptors.response.use(
  (response) => response,
  (error) => {
    if (error.response?.status === 401) {
      localStorage.removeItem('access_token')
      window.location.href = '/login'
    }
    return Promise.reject(error)
  }
)

export default apiClient
```

## 9. 주의사항 및 Known Issues

### 9.1 라우터 순서
- `/community/write`는 반드시 `/community/:id` 보다 먼저 정의
- 그렇지 않으면 'write'가 ID로 인식됨

### 9.2 캐러셀 레이아웃 시프트
- 장르 탭 변경 시 깜빡임 방지를 위해 로딩 오버레이 패턴 사용
- `v-if` 대신 `v-show` 또는 항상 렌더링 + 오버레이 권장
- `min-height` 설정으로 레이아웃 안정화

### 9.3 다크모드 적용
- 모든 새 컴포넌트는 `:root.dark` 스타일 필수 추가
- `transition: all 0.3s` 추가로 부드러운 전환 구현

### 9.4 이미지 로딩
- 공연 포스터는 외부 URL (KOPIS API)
- `@error` 핸들러로 fallback 처리 권장
```vue
<img
  :src="poster || 'https://via.placeholder.com/400x560?text=No+Poster'"
  @error="handleImageError"
/>
```

### 9.5 별점 시스템
- 0.5 단위로 별점 입력/표시
- `star-half` 오버레이 방식 사용
- 마우스 위치 계산으로 0.5/1.0 구분

### 9.6 반응형 Breakpoints
- 모바일 우선 (Mobile First) 방식
- 480px, 768px, 1024px, 1280px 기준
- 각 컴포넌트마다 반응형 스타일 확인 필요

### 9.7 API 응답 형식
- 목록 API: `response.data.results` 또는 `response.data` (둘 다 체크)
- 상세 API: `response.data` 직접 사용
- 페이지네이션: `results`, `count`, `next`, `previous` 포함
